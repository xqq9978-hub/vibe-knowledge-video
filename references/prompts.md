# 阶段提示词

使用时把 `{{…}}` 替换成当前项目的内容。范例只说明格式，不要把范例主题写死。

## 阶段1：选题推荐

```text
请为 Vibe 知识大赏风格的无旁白中文字幕知识短片推荐10个选题。
受众：{{目标受众，默认大众}}
领域偏好：{{领域，可留空}}
画幅：{{16:9 或 9:16}}，目标片长：{{秒数或"由内容决定"}}

判断标准：受众广、有反转、画面感强（能用一个装置的连续变化讲清楚）。
每题给出：标题｜核心问题｜具体演示过程｜推荐理由｜视觉效果。
最后推荐最适合的3个，并说明取舍。
如需近期抖音案例，必须检索并注明标题、作者、链接、日期；查不到就直说。
```

## 阶段1：确认已有主题

```text
主题：{{用户给的主题}}
请概括：核心问题、成立条件、演示方向（用什么对象、怎样变化），
并确认画幅与片长。不要重新推荐10个选题。
```

## 阶段2：知识核实

```text
主题：{{主题}}
列出视频要表达的每一条结论、数字、公式和实验条件。
每条注明：可靠来源链接（论文/大学/官方机构优先）、核实状态（已核实/部分核实/未核实/有争议）、
在视频中的呈现方式（真实结论/类比/示意数据）。写入 facts.md。
```

## 阶段2：分镜设计

```text
主题：{{主题}}；锚点对象：{{贯穿全片的对象}}
风格：{{参考分析结果，或 default-style.md 的“夜景沙盘”}}
章节：{{按时间地点划分，参考 default-style.md 的镜头清单模板}}
画幅：{{尺寸}}；字幕每屏 ≤{{18 或 14}} 字

按"困惑 → 现象 → 命名 → 原理 → 反转/应用 → 回到锚点"组织镜头。
每镜写：编号｜暂定时间｜对象与动作｜变化前→后｜字幕｜转场｜观众应理解什么。
名词要对应画面上可辨认的对象，动词要对应真实发生的动作。
字幕关键词用 [[金:词]] [[红:词]] [[青:词]] 标记，每句最多1–2处。
然后用共享的 Remotion 组件渲染每镜大图、关键前后图和总览拼图。
```

## 阶段3：卡点规划

```text
音乐文件：{{路径}}；分析结果：{{analyze_beats.py 输出}}
已批准分镜：{{storyboard.md}}
把镜头切换和关键动作的开始/落定对齐到选定的重拍，补全 beat-plan.csv：
事件｜秒｜帧号(round(秒*30))｜镜头｜动作开始/落定｜音效预设｜依据。
字幕阅读时间不能被压缩；标出检测不确定的拍点。
```

## 阶段3：音效设计

```text
按 beat-plan.csv 中的音效列，用 scripts/synth_sfx.py 生成音效。
同类动作复用同一声族，用 --gain 调整强弱；不是每个动作都要响。
输出 sfx/ 目录与 sfx/manifest.json（文件、预设、参数）。
```

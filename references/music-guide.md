# 背景音乐获取指南

**本 Skill 不附带任何音乐。** 担心版权问题，背景音乐需要使用者自己准备并放进本地，不随仓库发布。

## 1. 放在哪里

```text
assets/music/vibe-knowledge-tune.wav   # 推荐文件名，也支持 .mp3
```

- 文件名不同也可以，使用时告诉助手实际文件名，或在对话里直接上传音频。
- 支持 wav、mp3、m4a 等常见格式；wav 音质最好，mp3 体积小。
- `.gitignore` 已阻止该目录的音频上传到 GitHub。

调用：

```text
使用 vibe-knowledge-video 技能帮我做一条知识短片，
背景音乐用本地的 Vibe Knowledge Tune。
```

## 2. 去哪里找（按推荐顺序）

### ① 明确可商用 / 开放授权的曲库（最推荐）

| 来源 | 说明 |
|---|---|
| 剪映 → 音频 → 音乐，筛选"可商用" | 中文环境最方便，按剪映的授权条款使用 |
| YouTube 音频库（YouTube Studio → 音频库） | 免费，部分需署名 |
| Pixabay Music（pixabay.com/music） | 免费，可商用，一般无需署名 |
| Free Music Archive（freemusicarchive.org） | 按每首的 CC 协议使用 |
| Incompetech（incompetech.com） | CC BY，需署名作者 Kevin MacLeod |

适合本风格的搜索词：`ambient piano`、`cinematic documentary`、`lofi calm`、`科技 纪录片 钢琴`。速度 90–120 BPM、有清晰段落变化的曲子最好卡点。

下载时保存授权页面截图或链接，CC BY 音乐要在视频简介里署名。

### ② 抖音站内音乐（只在抖音发布时）

抖音曲库的音乐在抖音站内发布时通常可以使用，但**不代表可以下载后用在别处**。推荐做法：

1. 在抖音里看到喜欢的配乐，点右下角旋转的唱片 → **收藏**，记下歌名和作者。
2. 去正规渠道（音乐平台、曲库）找同一首歌的音频，用于本地卡点制作。
3. 发布到抖音时，可在发布页选用站内同名音乐，并把原视频音量关掉或调低。站内版本如果和本地版本起点不同，会影响卡点，发布前要预览确认。

### ③ 从视频中分离音频（只限你有权使用的视频）

适用于：你自己拍摄或制作的视频、你购买或获得授权的素材、明确允许再使用的作品。

- **剪映**：新建项目 → 音频 → **提取音乐** → 选择视频文件，即可只导入声音。
- **命令行（ffmpeg）**：
  ```bash
  ffmpeg -i 视频.mp4 -vn -ac 2 -ar 44100 -c:a pcm_s16le assets/music/vibe-knowledge-tune.wav
  ```
- 抖音视频可以在 App 里 **分享 → 保存本地**（作者允许下载时才有这个选项），再按上面方法分离。

⚠️ **能下载不等于有授权。** 别人视频里的配乐和原声，版权属于原作者或唱片公司。分离出来做个人学习、卡点练习一般风险较低；**用于公开发布的视频，或上传到 GitHub 等平台再分发，都可能侵权**。不确定时，优先选择第①类曲库。

## 3. 助手的处理规则

- 用户选择背景音乐时，先检查 `assets/music/` 或对话里上传的文件；没有就说明，并给出本指南第2节的获取方式。
- 只有用户明确要求，并确认自己有权使用时，才从用户提供的视频中分离音频；不主动从参考视频中提取音频。
- 来源或授权不明的音乐：可以用于本地制作和卡点分析，但交付时要提醒用户"发布前自行确认使用权限"，并在 `project-state.md` 记录音乐来源与授权状态（已确认 / 未确认）。
- 不把任何音乐写入 Skill 仓库，不帮助上传到公开平台再分发。

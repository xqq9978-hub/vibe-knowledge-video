# 默认视觉风格："夜景沙盘"

没有用户参考时使用。本风格是对参考片《多修一条路，为什么反而更堵？》（抖音创作者 Iwanau，16:9，约149秒）的画面分析总结，**仅提炼通用的设计语言**：仓库中不包含原片、截图或其任何素材，也不复制其水印、署名和具体画面。使用时要做原创内容，不要冒充该创作者，也不要说自己参考过原片（除非用户这次真的提供了它）。

## 1. 整体气质

**深夜城市 + 发光的模型沙盘**。现实场景（城市夜景、手机导航、报纸、论文）负责把观众带进来，抽象模型（发光路线、数字面板、弹簧绳子）负责讲清原理。两者用同一套暗色底和暖金色光统一起来，像一部安静、精致的数据纪录片。

## 2. 色彩

| 用途 | 颜色 | 说明 |
|---|---|---|
| 背景 | `#0B111F` 深海军蓝 / `#0B0A0B` 近黑 | 带轻微暗角和极淡网格或城市方块纹理 |
| 主光、正常状态 | `#F9F2DA` 暖奶白 | 路灯、节点、正常路线上的粒子 |
| 强调、标题、关键词 | `#D7B370` 香槟金 | 标题渐变 `#B19566 → #E6CF9A` |
| 新事物、另一种选择 | `#5EA6BA` 冷青蓝（发光 `#4FC3E0`） | 新路、短绳、切换后的状态 |
| 变差、拥堵、警示 | `#E44E48` 珊瑚红 | 拥堵路段、变慢的数字、"更慢" |
| 变好、通过 | `#4CD07D` 绿 | 只少量用于导航 UI 和"✓" |
| 次要文字 | `#8E8A80` 灰 | 注释、单位、图例 |

规则：**颜色就是状态**。同一对象从奶白变红就代表变差，观众不用读字也能看懂。一个画面里最多用2种强调色，金色永远留给关键词和标题。

## 3. 画面元素

1. **时间戳 HUD 卡片**（左上角）：圆角深色半透明卡片，细边框；大号粗体金色数字（年份或数据），下面一行小字"地点 · 事件"（如"1990 / 纽约 · 地球日"）。章节切换时更新。
2. **实时数据面板**（左上角，模型场景）：标题小字 + 超大数字 + 单位（如"42 分钟"），下面2–3行对比数据；数字随画面实时滚动，变差时变红。
3. **贴附标签**：小号深色圆角框 + 细引线指向对象；第一行粗体白字（"窄路 = 弹簧"），第二行灰色小字补充。关键标签可用青蓝或金色字。
4. **发光路线**：路线是半透明管道，里面流动着小光点（每个光点代表车、粒子等实体）。光点的密度和速度对应流量和速度；拥堵时变红、变密、变慢。
5. **节点**：发光圆点 + 小标签（"家""公司"）。
6. **现实场景**：俯视的夜景城市网格（暖色街灯沿街排列、景深和光斑）、手机导航 UI、旧报纸、论文首页。现实场景用来交代"真实发生过"，叠加原理图（例如把论文里的菱形网络图描出来）连接现实与模型。
7. **类比装置**：换一种物理装置讲同一个原理（如弹簧 + 绳子 + 刻度尺），刻度尺和数字面板保持和主模型一致的单位。
8. **进度清单**（解决方案段落）：左上角"那怎么办 1/3"，逐项打勾。
9. **标题卡**：深色放射光芒背景；小号英文大写字母间距拉开的副标题（如"BRAESS'S PARADOX · 1968"）；金色衬线大标题带柔光；下方一个极简线框图标。
10. **金句卡与参考资料卡**：结尾用细边框卡片放一句金句（可配一句古文出处）；最后一屏列出参考文献。

## 4. 字体

| 用途 | 字体 | 样式 |
|---|---|---|
| 标题、金句 | Noto Serif SC Bold（思源宋体） | 金色渐变 + 柔光 |
| 英文副标题 | Cormorant / Noto Serif，全大写 | 字间距 0.4em，低透明度 |
| 字幕、标签 | Noto Sans SC Medium/Bold | |
| 大数字 | Oswald / Barlow Condensed 等窄体粗体 | `tabular-nums`，避免数字滚动时抖动 |

字体都是 SIL OFL 开源许可，放进工程 `public/fonts/`。

## 5. 字幕

- 底部居中、单行，横屏约 40–44px（1920 宽下约 56px）。
- 白色偏暖（`#ECE8DE`）文字，放在**半透明深色圆角底条**上（`rgba(18,18,22,0.6)`），底条随文字宽度变化。
- **关键词上色**：每句最多1–2个词，金色表示重点/新概念，红色表示变差/反转，青蓝表示新事物。例如：给路网**多加一条路**（金），可能让所有人**更慢**（红）。
- 参考片约每 3.3 秒一句；短句 2 秒，含数字的句子 4–5 秒。

## 6. 镜头与动作

- **冷开场**：先放结论画面（例如路线全部变红），抛出问题，再进标题卡。
- **章节 = 时间地点**：用时间戳 HUD 切换"过去的真实事件 → 今天的日常 → 理论提出的时刻 → 模型推演 → 解决方案 → 回到开头的城市"。
- **结尾回到锚点**：回到开场的城市或模型，配一句新理解（"他们只是少了一条'捷径'"）。
- 几乎没有硬切：用慢速推拉摇移、叠化、对象延续来转场。
- 镜头缓慢推进或平移，带浅景深和光斑；模型场景基本固定机位，让观众专心看变化。
- 动作节奏：先停住让观众看清初始状态 → 一个变化发生（新路亮起、车流改道、数字滚动）→ 停稳 → 字幕点出结果。
- 粒子只用来表示实体（车流、人流），不加无意义的装饰粒子。

## 7. 声音

- 背景音乐：温和的钢琴/氛围电子，参考片估计约 112 BPM，有明显的段落变化（引入、模型推演、解决方案、结尾）。
- 音效轻：节点出现用短拨弦，路线亮起用轻滑音，数字落定用克制的落定音，反转揭晓用钟琴。
- 参考片响度约 -10.7 LUFS、峰值偏高；本 Skill 仍按 -14 LUFS / -1 dBTP 交付，避免削波。

## 8. 可复用风格描述

```text
深海军蓝夜景底色的数据纪录片式科普动画。现实场景用俯视夜景城市网格（暖色街灯、景深光斑）、
手机导航界面、旧报纸和论文；原理部分用发光的模型沙盘：半透明路线管道里流动着代表实体的光点，
颜色表示状态（奶白正常、珊瑚红变差、冷青蓝新事物、香槟金重点）。左上角圆角深色 HUD 卡片显示
年份或实时数字，对象旁有带引线的小标签。底部居中单行字幕放在半透明深色底条上，关键词上金色或红色。
标题卡为深色放射光背景上的金色衬线标题，配字母间距很大的英文副标题。镜头缓慢推移，叠化转场，冷开场，
结尾回到开场的场景。
```

## 9. 镜头清单模板（可按主题替换）

| 段落 | 占比 | 画面 | HUD |
|---|---|---|---|
| 冷开场 | 5% | 结论画面 + 问题字幕 | 无或数字 |
| 标题卡 | 3% | 放射光 + 金色标题 + 线框图 | 无 |
| 真实事件 | 15% | 夜景城市 / 报纸 | 年份 · 地点 |
| 今天的日常 | 10% | 手机导航等生活场景 | "今天 · 场景" |
| 理论出处 | 8% | 论文 + 原理图描线 | 年份 · 人物 |
| 模型推演 | 30% | 发光沙盘，数字实时变化 | 实时数据面板 |
| 类比装置 | 12% | 另一种物理装置 | 同单位面板 |
| 解决方案 | 10% | 真实案例 | 进度清单 |
| 回到锚点 + 金句 | 5% | 开场场景 + 金句卡 + 标题 | 年份 |
| 参考资料 | 2% | 文献列表 | 无 |

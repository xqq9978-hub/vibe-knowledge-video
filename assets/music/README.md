# 本地背景音乐

**本仓库不附带音乐。** 担心版权问题，请在使用 Skill 时自己准备音频并放在这里：

```text
assets/music/vibe-knowledge-tune.wav   # 曲名 Vibe Knowledge Tune（Vibe知识小曲），也支持 .mp3
```

- 这个文件夹里的音频只在你的电脑上使用，`.gitignore` 会阻止它上传到 GitHub。
- 去哪里找音乐、怎样从视频中分离音频、版权注意事项：见 [references/music-guide.md](../../references/music-guide.md)。

调用方式：

```text
使用 vibe-knowledge-video 技能帮我做一条知识短片，
背景音乐用本地的 Vibe Knowledge Tune。
```
